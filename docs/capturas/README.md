# Capturas del Manual de Usuario

Esta carpeta guarda las imágenes que usa `MANUAL_USUARIO.md`.

**Cómo usarla:** sacá cada captura, guardala acá con el nombre exacto de la lista
y la imagen aparecerá sola en el manual. Formato recomendado: PNG.

| Archivo | Qué mostrar |
|---|---|
| `01-login.png` | Pantalla de inicio de sesión (usuario, contraseña, botón Ingresar) |
| `02-instalar-pwa.png` | Opción "Agregar a pantalla principal" en el navegador del celular |
| `03-pantalla-login.png` | Detalle de la pantalla de ingreso (botón "Ver" contraseña) |
| `04-gestion-remates.png` | Pantalla de remates: seleccionado, crear, vigentes y finalizados |
| `05-formulario-carga.png` | Formulario "Registrar Ingreso" completo |
| `06-lista-lotes.png` | Lista de lotes con buscador, orden y tarjetas |
| `07-mapa-corrales.png` | Mapa de corrales con la referencia de colores |
| `08-barra-superior.png` | Barra superior (remate activo, cabezas, botones) |
| `09-crear-remate.png` | Formulario para crear un remate nuevo |
| `10-cargar-lote.png` | Un lote recién cargado en la lista |
| `11-foto-marca.png` | Cámara abierta para sacar la foto de la marca |
| `12-visor-foto.png` | Visor de imagen ampliada con zoom |
| `13-editar-lote.png` | Ventana "Editar lote" |
| `14-eliminar-lote.png` | Ventana de confirmación para eliminar |
| `15-habilitar-pasillos.png` | Opción para habilitar pasillos como corrales temporales |
| `16-pdf-exportado.png` | Ejemplo del PDF generado |
